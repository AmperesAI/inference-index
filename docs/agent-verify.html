Same agent. Different model. Different behavior. Agent platforms swap models constantly — for cost, availability, routing. Agent Verify runs your agent's task suite across candidate models and certifies the swap before your users find out the hard way.

⚠ SAMPLE REPORT — illustrative format only, not measured data. Generate a real report in ~2 minutes: python3 pipeline/agent_verify.py against your own endpoints (OpenAI, Nebius Token Factory, Databricks serving, Together, Groq, vLLM — anything OpenAI-compatible).

The five dimensions

1 · TOOL FIDELITY
Does the candidate call the same tools the baseline called — and no phantom ones?
2 · ARG VALIDITY
Do tool arguments parse and contain every required key?
3 · SCHEMA VALIDITY
Do JSON-output tasks return parseable, correctly-shaped objects?
4 · NON-REFUSAL
No refusals or empty outputs on benign tasks.
5 · EQUIVALENCE (PANEL)
Judge panel scores candidate vs baseline 1–5 — reported as median + spread, never one judge.
Why a panel? The Inference Index research showed 10 judges scored the identical outputs anywhere from 61% to 97% preserved. One judge is an anecdote. A panel with a disclosed spread is a measurement.

Run it against your fleet

One command. First --model is your baseline, the rest are swap candidates. Works with any OpenAI-compatible endpoint — which is exactly what multi-model agent platforms (Databricks serving endpoints, Nebius Token Factory, OpenAI, Groq, vLLM) already speak.

python3 pipeline/agent_verify.py \
  --tasks pipeline/agent_tasks.jsonl \
  --model "baseline|https://api.openai.com/v1|gpt-5|OPENAI_API_KEY" \
  --model "swap-1|https://api.tokenfactory.nebius.com/v1|meta-llama/Meta-Llama-3.1-8B-Instruct-fast|NEBIUS_API_KEY" \
  --judge "judge-1|https://generativelanguage.googleapis.com/v1beta/openai|gemini-2.5-pro|GEMINI_API_KEY" \
  --out docs/agent-verify-report.json

Ten agent-shaped tasks ship in pipeline/agent_tasks.jsonl (tool calls, multi-arg bookings, JSON extraction, a no-tool distractor that catches over-eager tool callers). Replace them with traces from your own agent for a fleet-specific certification.
