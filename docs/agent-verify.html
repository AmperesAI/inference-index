Methodology

Five dimensions. One verdict.

01
Tool Fidelity
Calls the same tools the baseline called — and no phantom ones. The distractor task catches over-eager callers.
02
Arg Validity
Tool arguments parse as JSON and contain every required key.
03
Schema Validity
JSON-output tasks return parseable, correctly-shaped objects.
04
Non-Refusal
No refusals or empty outputs on benign tasks.
05
Equivalence · Panel
A judge panel scores candidate vs baseline 1–5 — reported as median + spread, never one judge.

Why a panel? The Inference Index research put identical outputs in front of 10 independent judges: preservation scores ranged from 61% to 97%. One judge is an opinion. A panel with a disclosed spread is a measurement.
