The Problem

Swaps ship blind

Every agent platform re-routes the model beneath its agents — for cost, availability, routing. The prompt is identical; the behavior is not: different tools called, malformed arguments, broken JSON, silent refusals. There is no standard, portable pre-swap test — every team hand-rolls its own, or ships and prays.

The Research Insight

Even the judges disagree

Our research (under review at TMLR, 2026): downshifting a workload 70B→8B cuts cost 98.35% — but when 10 independent judges scored the identical output pairs, preservation ranged 61–97%, median ~90%. A single judge is an anecdote. A panel with a disclosed spread is a measurement. Nobody was pricing this — so we built the instrument.

Product 1 · Today's Build

Agent Verify

Run your agent's task suite across a baseline and N swap candidates on any OpenAI-compatible endpoint. Five behavioral dimensions. One verdict: CERTIFIED / CAUTION / FAIL.

  • Tool fidelity — same tools as baseline, no phantom calls (a distractor task catches over-callers)
  • Arg + schema validity — arguments parse, JSON outputs hold shape
  • Panel equivalence — judge panel, median + spread, never one judge
  • CI-ready — single stdlib Python file, exits non-zero on FAIL, ~5 min per run
