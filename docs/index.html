How it stays live

Apify crawls 11 official pricing pages (they're JS-heavy — that's why a headless crawler, not curl) → n8n extracts & diffs prices every 6h, fires market-move alerts, and dispatches to GitHub → GitHub Actions recomputes $/MQT and commits data.json → this page redeploys. Zero servers. A market move becomes a live index change in minutes. Bolt powers the Pilot Console — paste a workload, get a per-workload savings simulation. Full pipeline in the repo.
